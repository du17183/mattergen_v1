# Adaptive Budget：仅作为未来工作

**状态：DESIGN ONLY / NOT IMPLEMENTED / NOT VERIFIED。** 此文件是论文展望的候选方向，不属于已确认创新点1，不产生新的 seed、阈值、模型或实验结论。当前的 2.2× Fixed-K2 保持不变。

## 要回答的问题

固定 K=2 给所有样本支付 4,400 次 MatterGen score 调用，但历史 C1 的 128 个样本中有 75 个最终仍输出 C0。回退说明候选未被接受，**不能直接推出这些样本可被事先识别为“容易”**。未来问题应被限定为：能否仅利用 C0 完成时可观测的信号，预判值得投入两个额外后缀的样本，并在新的配对确认集上以更低**实际总成本**保持相近的代理属性误差和质量护栏？

```text
保存 C0 第 400 步状态/RNG → 完成并评价 C0
                       ↓ 预先冻结的 difficulty rule
         easy ──→ 直接输出 C0
         hard ──→ 恢复同一前缀，运行原 Fixed-K2 两个后缀
                            ↓ 原 SAFE-A 验证与 C0 回退
```

算法不能因为“动态”而偷换已有 GPulse/PPulse、接受阈值或目标属性。若 `p` 为 hard 比例，生成器名义预算为 `2,000+2,400p` score calls/样本，即 `1+1.2p` 倍 C0；这是**理论调用账本，不是实测速度**。C0 属性/质量代理、硬样本的额外两个候选验证、状态缓存与恢复都须计入 all-in 墙钟时间和显存。

## 可校准的难度信号及风险

| C0 时刻可见的信号 | 研究用途 | 必须防范的误差 |
|---|---|---|
| CHGNet 预测属性误差 | 判断是否存在明显属性改善空间 | 同一代理又参与 SAFE-A 与主终点，易产生选择乐观和回归均值；“C0 误差大”不等于“两个后缀能安全改善”。 |
| C0 的代理 E-hull/Stable/Validity | 识别质量高风险或无效输出 | MatterSim 对所有样本的评估耗时，且高风险 C0 不一定存在合格候选；要避免使用终点后验信息。 |
| 多模型分歧/置信校准 | 探索代理不确定性 | 单个代理的分数不是已校准置信度；新增模型本身也有计算和训练代价。 |

不应从现有 C1 或 K0–4 结果挑一个“看上去正确”的门槛直接用于确认。那会把结果后选择伪装成预注册方法。

## 两阶段验证要求

1. **独立 calibration set**：不得与 C1-128、Best-of-2 cohort、Budget Scaling cohort 或未来确认集重叠；只在此集合评估“C0 可见信号”对 **C0−Fixed-K2 安全增益** 的预测能力，并选择一个简单规则/阈值。把失效/缺失信号的处理、路由成本、可接受的硬样本比例一并冻结。
2. **新鲜 fresh confirmation set**：注册前序列化并哈希路由规则、预处理、Fixed-K2 分支、SAFE-A、主要成本和 Property MAE 指标及 GO 判据。与总成本匹配的 always-C0、always-Fixed-K2 和独立 Best-of-2/等预算基线比较。报告 20k 配对 bootstrap CI、W/T/L、Property MAE、E-hull、Stable、NUS、Validity、Novel、Unique、score 与验证器调用、端到端 wall time 和失败/回退率。
3. **预先决定研究目标**：例如“在预定 MAE 非劣界和质量护栏下节约 all-in 时间”，或“固定 all-in 预算下提高 MAE”；不能看到结果后在二者之间切换。未通过则保留负结果，不补救调参或续加 seed。

当前数据只支持“值得研究是否能降低无效分支开销”的假设，不支持“自适应预算已比 Fixed-K2 或 Best-of-2 更优”。论文第6章未来工作可用两三句话介绍上述设计；摘要和主要贡献**不加入** Adaptive Budget。
