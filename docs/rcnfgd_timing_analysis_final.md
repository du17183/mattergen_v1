# RC-NFGD Timing Ablation：创新点2最终影响

状态：正式 32 paired seeds 四臂实验完成。

## 是否支持方法动机

Late（原方法）相对 C0 的 MatterSim MaxF 从 0.189865 降至 0.138639 eV/Å，配对差值 -0.051225 eV/Å，20k bootstrap 95% CI 为 [-0.068340, -0.037698]，32/32 个 seed 改善；平均力也下降 0.023993 eV/Å，95% CI 为 [-0.029829, -0.018790]。因此，新 cohort 支持“原始后期注入可改善代理力指标”，但并不证明后期注入相对其他阶段最优。

Early 与 Middle 的 MaxF 均值分别为 0.168597、0.140718 eV/Å；Late 对二者的直接配对 MaxF 差值区间分别为 [-0.131356, 0.066332]、[-0.066847, 0.077269]，均跨零。Early 的属性 MAE 均值较低，但 NUS 点估计从 C0 的 0.3125 降至 0.15625；Late 的属性 MAE 相对 C0 增加约 0.000066 Å⁻³。不能只看单一指标指定“最佳时机”。

## 标题与正文

推荐保留“面向冻结材料扩散模型的神经力场反馈引导方法”。建议把四臂机制消融加入第4章：正文报告原始 Late 相对 C0 的配对改善、Early/Middle 与 Late 的区间重叠、属性与 NUS 的代价及计算成本；摘要只可限定为“在当前 MatterGen/MatterSim 设置下，后期反馈可改善代理力指标”，不能写“后期最优”或“全面优于其他方法”。

## 与 Pareto 分析的关系

本次同一 32-seed cohort 的均值二维（Property MAE、MaxF）Pareto 前沿包含 Early、Middle、Late；这是描述性均值前沿，不代表统计显著优势。既有 C0/RC-NFGD/POST Pareto 来自独立历史 cohort，不能合并为同一配对前沿；POST 在原 cohort 的代理力效果更强这一负结果必须保留。

## 证据边界

实际 MatterSim 力模型调用均值为 C0 0、Early 931.5、Middle 500.0、Late 20.0 次/样本；端到端生成 wall time 均值为 86.7、258.5、106.5、88.3 秒，即约 1.00×、2.98×、1.23×、1.02×。时机阈值也改变累计力计算预算，故不是固定计算量的纯时机因果消融。记录的 CUDA event 是包含 CPU 等待的采样区间，不等于 GPU 活跃时间。MatterSim 与 CHGNet 均为代理模型；Stable/E-hull/NUS 为既有质量管线指标。无 DFT 验证、无跨生成模型普适性、无与 Fixed-K2 联合增益。若要严格分离“时机”与“力计算量”，未来须做等调用次数的预注册补充实验，不能据此修改本次结论。
