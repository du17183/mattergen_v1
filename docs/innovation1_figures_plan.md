# 创新点1论文图表升级设计（仅规划，不绘制/替换正文）

本计划按“**一图回答一个审稿问题**”组织，不以装饰性流程框或现有图数量决定版式。目标是学校硕士论文中的可复核矢量图，而非声称符合某个未指定期刊的正式投稿规范。新增两张方法/对照图；预算曲线可核对既有 `figures/search_framework/compute_performance_curve.pdf` 的数据后改为论文版。三图目前均**未插入论文**。新图不使用 AI 生成的晶体照片、虚构候选或无来源数值。

## 图1：预算约束验证选择推理总体框架

**核心结论：** 冻结 MatterGen 的额外推理预算被显式分配给有限候选，最终输出由冻结代理约束和参考回退共同决定。  
**Results-level 问题：** 方法做了什么、预算花在哪里、什么时候可能回退？  
**图型：** 单一主流程的 schematic-led 方法图，建议接近论文正文通栏宽度，最终按学校模板 `\linewidth` 试排。

从左向右或从上到下只保留五层：

```text
冻结 MatterGen + 条件 c + seed
         ↓ 共享前缀（第 0–399 步；800 score calls）
状态检查点 s400：原子种类 / 位置 / 晶胞 / RNG / 步序
         ├── C0 参考后缀 ─────────────┐
         ├── GPulse 后缀 ──────────────┤ 终点评价：CHGNet 属性；MatterSim E-hull/Stable；Validity
         └── PPulse 后缀 ──────────────┘              ↓ 冻结 SAFE-A
                                   合格且严格改善 → 最低代理误差候选
                                   否则 → 精确 C0
```

主图醒目展示 C0 参考路径与 SAFE-A 回退；预算角标写 `2,000 → 4,400 score calls (2.2×)`、`1 → 3 terminal evaluations`，**不可把 2.2×写成总 wall time**。条件、模型版本和 timestep 属于理想状态定义；旧 C1 checkpoint 未独立存储 condition/timestep 网格，图注需写“状态/调度由冻结实现共同恢复”，不能画成自包含跨版本文件。固定 K=2 用实线，未来动态预算/额外动作**不画入当前已验证方法**。

证据位置：第3章方法（建议 3.3–3.4）。图注说明这是算法示意，不承载性能证据；不在图上放“最优”“物理安全”“超越 Best-of-N”等标签。

## 图2：独立 Best-of-2 与共享前缀 Fixed-K2 的公平性对照

**核心结论：** 两种方法使用相同终点验证/回退，但候选来源及成本不同；新实验没有证明 Fixed-K2 更优。  
**Results-level 问题：** Fixed-K2 是否只是花更多计算后筛选？  
**图型：** 二面板方法—证据组合，不做两个纯装饰性平行流程。

| 面板 | 作用 | 必须呈现 |
|---|---|---|
| a. 轨迹来源与预算（较窄） | 建立对照定义 | Independent Best-of-2：两个从头独立完整采样，`4,000 score calls/2 终点`；Fixed-K2：一个共享前缀+C0/GPulse/PPulse，`4,400 score calls/3 终点`。两侧终点接**相同 SAFE-A**。用同色表示共同 C0，用不同线型表示独立全轨迹与共享后缀。 |
| b. 直接配对结果（主证据，较宽） | 限定方法主张 | 同一新 cohort `n=128` 的 Best-of-2−Fixed-K2 **配对**平均差 `−0.001410` 与 20k bootstrap 95% CI `[−0.005039,0.002167]`，零线清晰；旁边简列三臂 MAE `0.037623/0.028097/0.029506`。点估计对 Fixed-K2 不利，CI 跨零。 |

图注必须写：正的 Best-of-2−Fixed-K2 代表 Fixed-K2 的 MAE 更低；两者 **2.0× 对 2.2×、2 对 3 终点**，并非等预算因果控制；指标是同一 CHGNet 代理，存在选择偏差。图不能只画三根均值柱且省略直接配对差，也不能用大字号突出 Fixed-K2 的历史 C1 改善来掩盖新对照。历史 C1 结果可在相邻正文/表格独立说明，**不与新 cohort 共用 y 轴或配对连接线**。

证据位置：建议 3.5.1（或第5章主对照）；数值源 `results/search_baseline/{paired_results.csv,bootstrap_20k.json,table_best_of_n.csv,compute_accounting.json}` 与公平性审计。

## 图3：K=0–4 的预算—代理性能曲线

**核心结论：** 在同一冻结候选顺序下，增加候选使选中代理误差下降，但收益不均匀，K=2 只是成本折中。  
**Results-level 问题：** 预算宽度变化后，性能、边际收益与成本各怎样变化？  
**图型：** 以 compute–performance 为主的定量曲线。横轴必须为真实生成 score-call 倍数 `1.0,1.6,2.2,2.8,3.4×`，上方/下方辅以 K0–K4 离散标签；纵轴为 CHGNet Property MAE，点为新 Budget Scaling cohort `n=128` 的均值。主图误差棒定义为 **20k seed bootstrap 的均值 95% CI**。若另设小附图，展示相邻 K 的**配对边际增益 CI**，不要与主图均值 CI 混标；若版面紧张，边际结果放表格即可。

主图五点为 `0.035141/0.031636/0.028454/0.028419/0.024669`。在 K2/K3 附近标“边际近零”，K4 处标“更低 MAE，3.4×”；不得以此事后挑 K4 改写历史 Fixed-K2。图注必须说明：候选集合嵌套，SAFE-A 选择保证同 seed 的选中代理 MAE 随 K 不增；线段仅连接离散观测，不拟合平滑 scaling law。E-hull/Stable/NUS/Validity 和 Novel/Unique 不压到同一轴，放对应表格以免视觉上误报“全面质量改善”。

证据位置：建议 3.5.2。可审查既有 `figures/search_framework/{compute_performance_curve.pdf,search_width_curve.pdf}` 和 `results/budget_scaling/{table_budget_scaling.csv,bootstrap_20k.json}`；复用前须检查图注、数字和学校模板中的实际物理尺寸。

## 图表顺序、版式和质检门槛

论文证据顺序建议为 **图1 解释方法 → 图2 强基线/失败边界 → 图3 预算权衡**。图2 的不利对照属于主图，不应放到附录。旧 C1 主结果表继续独立保留，新增一张 Best-of-2 含 score/验证器调用的对照表；K0–4 的全质量矩阵放表格，避免三张图各重复同一 MAE 信息。

三图统一使用白底、一个中性 C0 色、一个独立采样色、一个 Fixed-K2 色；颜色外另用线型/标注区分。输出 PDF/SVG 可编辑文本，PNG 只作预览；最终宽度、字号和图注按学校模板实测，所有误差棒的 cohort、`n`、估计量和区间写清。若图2 采用多面板，最终绘制时需做面板对齐测量；所有 PDF 均须做字体下限与文本/图形碰撞检查。这里只给设计合同，不声称三张新图已通过渲染质检。
