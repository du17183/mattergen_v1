# 全文主线：两项独立的冻结模型推理增强

建议的英文叙事主题：**Trustworthy inference enhancement for frozen material generative models**。在论文中“trustworthy”应解释为**可复现状态、显式成本、冻结代理约束、负结果与证据边界均可审计**，不等于已获 DFT/实验验证的材料可信性，更不等于两方法组合已获证明。中文可用“面向冻结材料生成模型的可审计推理增强”。论文题目《基于深度学习的材料逆向生成》无需因本文件自动更名。

## 一个总问题、两个正交决策层

总问题：冻结的 MatterGen 已能提出晶体候选，但推理阶段仍需决定**把额外计算花在何处**，以及**何时引入外部物理代理反馈**；这两类决策必须在属性、局部结构和成本之间分别验证。

| 维度 | 创新点1：预算控制 / 验证选择 | 创新点2：物理反馈 / 后期引导 |
|---|---|---|
| 提问 | 如何在有限预算下保留 C0，生成并选择候选？ | 何时可以利用神经势原子力改变采样轨迹？ |
| 决策粒度 | **轨迹/终点级**：共享前缀、候选后缀、SAFE-A 与参考回退 | **步级**：可靠后期窗口内将 MatterSim 力映射到 position predictor，异常时退回原 score |
| 额外资源 | Fixed-K2 为 `4,400` MatterGen score calls（C0 的 2.2×）及 3 个终点评价 | 与其 C0 同为 `2,000` 主网络调用，另有 20 次在线 MatterSim 力调用；不宣称加速 |
| 主要指标 | 磁性密度条件任务的 **CHGNet 代理 Property MAE**；E-hull/Stable/Validity 等代理护栏 | **MatterSim 代理 MaxF、Mean Force、RMSD**；CHGNet 跨势均值核查和属性代价 |
| 冻结确认 | C1-128：`0.034796 → 0.026332`，24.32%，CI `[0.005817,0.011391]` | Formal256：MaxF/Mean Force/RMSD 分别下降 `29.81%/29.72%/14.17%`；CHGNet MaxF 均值下降 14.36% |
| 不利证据 | Linear-K2 未获额外支持；新 Best-of-2 点估计 `0.028097` 低于同 cohort 的 Fixed-K2 `0.029506`，直接 CI 跨零；K2 非最优宽度 | Property MAE `0.009757 → 0.009868`（恶化约 1.14%）；等预算 POST 在所测代理终态受力上更强；部分 CHGNet 尾部混合 |
| 主张边界 | 同代理验证/报告存在 verifier bias；未证明优于独立 Best-of-N | MatterSim 同源评价风险；CHGNet 仍是代理；未证明优于后处理或真实 DFT 力改善 |

**不可跨列直接比较绝对 MAE：**创新点1与2采用不同目标条件（创新点1磁性密度 `0.1`、创新点2 `0.2`）、独立 seed cohort、不同主要终点。不能把两项指标加权成未经预注册的“总分”，也不能把一项方法的基线均值挪到另一项图中。

## 推荐的论文叙事链

1. **第1章：**从冻结生成模型的推理决策困难引出两个研究问题。共同原则是“额外计算、外部反馈与风险必须显式记账和验证”，不是“统一的新采样器已解决两目标”。
2. **第2章：**提供三字段扩散、CFG、周期晶体状态、神经势、配对统计与代理评价的共同语言，不提前宣称任何结果。
3. **第3章：**由 Adaptive CFG 的负/混合探索推出预算约束验证选择接口；Fixed-K2 给出 C1 相对 C0 的确认；独立 Best-of-2 限定候选来源优势；K0–4 说明成本折中而非最优 K。
4. **第4章：**从局部受力问题进入阶段可靠性、周期坐标力映射和 RC-NFGD；正式 Formal256 与 CHGNet 均值证据之后，正面报告 Property MAE 代价、POST 更强和有界消融不足。
5. **第5章：**用统一证据层级而不是统一性能排名并列两项方法。增加新 Best-of-2/K0–4 在第5章的证据表和成本账本；单列“强基线与负结果”讨论。联合兼容实验是**历史 Adaptive CFG + 力反馈**，不是 Fixed-K2 + RC-NFGD 的完整组合。
6. **第6章：**总结两种**独立可审计接口**，把下一步写成独立 DFT 验证、跨任务复现和 Adaptive Budget 的校准—新鲜确认，而非宣称已形成联合最优系统。

建议全文的总贡献句：

> 本文以冻结 MatterGen 为共同基础，分别研究“如何在明确推理预算下验证并选择候选”和“如何在阶段可靠条件下引入代理原子力反馈”。两条路线在各自预注册代理任务上获得有限支持，并通过独立多样本筛选、学习型分配、等预算后处理及兼容性实验明确了未被支持的更强命题。

## “优秀论文”应主动呈现的四条界限

- **代理不是 DFT。**创新点1的属性/质量选择依赖 CHGNet/MatterSim；创新点2的主要力结果也依赖 MatterSim，跨势 CHGNet 仅降低部分同源解释风险。`DFT_VERIFIED=false` 始终可见。
- **强基线不能藏。**Best-of-2 数值方向不利于 Fixed-K2，且预算/终点数不匹配；POST 在同一代理力指标上更强。两者必须在主文而非附录。
- **失败不是新贡献。**Adaptive CFG、Linear-K2 和联合兼容性未通过各自判据，是研究路线收缩和适用边界的证据，不写成成功模块。
- **互补不等于协同。**两项方法共享冻结模型、配对统计、回退与审计原则，但目标、介入时刻和成本不同；当前 `JOINT_SYNERGY=NOT_SUPPORTED`，也没有直接完成 Fixed-K2 × RC-NFGD 的正式确认。

该主线允许在不新增算法的前提下提升论文质量：统一术语、明确反事实与确认结果的层级、把 compute/verifier 成本写进方法、将所有限制与负结果放在读者看得见的位置。当前 LaTeX/PDF 尚未按此方案修改。
