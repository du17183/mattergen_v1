# 创新点1最终学术定位（供论文修订，不改冻结实验）

**建议名称：面向冻结扩散生成模型的预算约束验证选择推理方法**  
**English: Budget-Constrained Verifier-Guided Inference Framework**

本文件依据现有 127 页论文 PDF（2026-09-22 编译）、其 LaTeX 摘要/第1、3、5、6章，以及 2026-09-28 完成的两组新实验。**当前 PDF 尚未包含 Best-of-2 和 K=0–4 结果**，下述内容是待整合的表述建议，不是“正文已修改”或新的实验结论。历史 C1-128、Linear-K2 和两组新 cohort 不合并估计。

## 1. 研究问题和主张边界

冻结 MatterGen 可以重复调用，但固定一次采样不保证目标属性代理误差低；直接在线改变单条轨迹可能产生不可逆偏离。研究问题不是“找到最优 CFG 值”，而是：**在明确计入生成器与验证器开销的有限推理预算下，如何保留可复现的参考输出、产生有限候选，并按预先冻结的代理属性/质量条件决定接受或回退？**

建议把贡献写成一个有边界的推理接口及其 Fixed-K2 实例：参考轨迹保持、共享状态/RNG 重放、预定候选后缀、终点约束选择和精确参考回退。**不写成 CFG 优化算法、超越 Best-of-N 的搜索、通用最优搜索或已验证的物理安全算法。**候选动作可以使用 CFG 脉冲，但 CFG 只是候选策略的实现，不是贡献的全部定义。

## 2. 方法抽象与实际实现的对应

| 接口 | 概念定义 | Fixed-K2 冻结实例及核查边界 |
|---|---|---|
| State (s_t) | 扩散图状态（原子种类、位置、晶胞）、步序/数值 timestep、Python/NumPy/PyTorch CPU/CUDA RNG、目标 condition，并绑定冻结模型与调度 | 第 400 步克隆采样 `batch` 和 RNG；存储 `branch_point`。condition 随 `batch` 和冻结脚本传递，但**未在旧 checkpoint 中独立序列化/哈希**；数值 timestep 网格由冻结配置重建，而非存入独立张量。不可把旧存档写成跨版本完全自描述状态。 |
| Action (a) | 预声明的后缀轨迹策略 | C0 continuation，以及固定 `GPulse`、`PPulse`；这些是改变后缀引导的动作，不是训练出的规划器。 |
| Transition | 从同一克隆状态和 RNG 快照恢复后，由冻结 MatterGen predictor–corrector sampler 完成后续采样 | 不修改主网络权重；C1 的 128 个独立全程 C0 与共享前缀 C0 均通过精确重放核验。 |
| Terminal verifier | 代理 Property MAE、E-hull、Stable、评价有效性/几何有效性 | SAFE-A 只有在 CHGNet 属性绝对误差比 C0 严格低 `1e-6` 以上、Validity 与 Stable 不下降、双方 E-hull 有限且候选 E-hull ≤ C0+`0.01 eV/atom` 时才允许接受。Novel、Unique、NUS 是集合层面报告指标，**不是逐样本选择条件**。 |
| Output | 合格候选中属性误差最低者；否则精确 C0 | “零最终属性损失”是相对**同一选择代理**的规则性质，不能当作独立验证器/DFT 的无伤保证。 |
| Budget | 分开记录生成 score calls、CHGNet/MatterSim 终点调用、时间、显存 | C0 为 2,000 score calls；Fixed-K2 为 4,400（2.2×）、3 个终点；2.2×**不含**验证器和完整端到端时间。 |

因此可称 Fixed-K2 为“框架下的**固定预算实例**”，不暗示 K=2 已被证明最优、动作库可任意扩展而保持效果，或已经实现样本级动态预算。

## 3. 证据阶梯：必须把正结果与反证放在一起

| 证据 | 结果 | 允许的结论 | 不允许的结论 |
|---|---|---|---|
| 历史 C1-128，独立确认 | C0 `0.034796` → Fixed-K2 `0.026332`，相对改善 24.32%；配对增益 95% CI `[0.005817, 0.011391]`；2.2× score calls | 当前 checkpoint/磁性密度任务/代理协议下，Fixed-K2 相对自身 C0 有收益 | Fixed-K2 在等预算下优于独立采样，或真实 DFT 属性改善 |
| Linear-K2 | Phase B 区间跨零；C1 `0.027522`，未优于 Fixed-K2 `0.026332` | 当前分支前特征、样本量和线性分配未得到独立支持 | 所有学习型分配器均无价值 |
| 新 Best-of-2 cohort，128 对、与 C1 分离 | C0 `0.037623`；独立 Best-of-2 `0.028097`（2.0×、2 终点）；Fixed-K2 `0.029506`（2.2×、3 终点）。直接配对 Best-of-2−Fixed-K2 `−0.001410`，95% CI `[−0.005039, 0.002167]` | 更多推理计算加冻结验证选择可降低**代理** MAE；独立方法数值更好、成本更低，但直接差异未排除零 | Fixed-K2 优于 Best-of-N；两者“同预算”；独立 Best-of-2 已被统计证明优于 Fixed-K2 |
| 新 Budget Scaling cohort，另 128 对 | K0–4 分别 `0.035141/0.031636/0.028454/0.028419/0.024669`，预算 `1.0/1.6/2.2/2.8/3.4×` | 在冻结候选顺序和 SAFE-A 下，多候选的**选中结果**呈现预算—代理误差权衡；K3 边际近零、K4 继续改善 | K=2 最优；存在平滑普适 scaling law；误差单调下降独立证明了搜索算法优势 |

K 组是嵌套候选集合，SAFE-A 不会接受比当前 C0 更差的属性代理误差；因此每个样本的选中误差随 K 不增具有**算法结构性**。Budget Scaling 的价值在于量化边际收益和代价，而不是把这一单调性当作新的独立发现。不同 cohort 的 C0 均值不同，绝不能把 C1、Best-of-2 和 Budget Scaling 当成同一批样本画直接差值。

## 4. 为什么 Best-of-2 结果不“推翻”贡献，同时它确实收窄贡献

Independent Best-of-2 与 Fixed-K2 共用冻结终点验证/回退协议，却采取不同候选来源。其正结果说明**额外推理计算与选择本身就是强基线**；这支持研究预算约束推理的问题重要性。Fixed-K2 的可陈述差异是：保存同一参考及 RNG、共享前缀生成具有明确动作语义的后缀、逐样本代理质量约束与精确回退，并将这些操作成本化、可审计化。

但这些是**方法结构和复现性贡献**，不是已经验证的性能优势。Best-of-2 点估计更低，且其生成成本 2.0×、终点 2 个；Fixed-K2 为 2.2×、3 个。两者既不严格等生成预算，也不等验证预算，直接差异的 CI 跨零。故论文应主动写明：“当前实验证据尚不能证明共享前缀分支相对独立多样本生成具有独立效能优势。”这句话比回避对照更能体现优秀硕士论文的可信度。

## 5. 适合论文的“贡献句”与防误读注释

> 本文研究冻结晶体扩散模型的推理阶段预算约束选择问题，提出以精确参考轨迹、有限候选后缀、冻结代理验证条件和参考回退构成的推理接口，并以 Fixed-K2 作为固定双候选实例。在 C1-128 上，该实例相对 C0 降低代理属性误差；独立 Best-of-2 和 K=0–4 实验进一步界定了额外计算、候选来源与预算宽度的作用和局限。

紧随其后必须说明：独立 Best-of-2 在新 cohort 的均值数值上优于 Fixed-K2；这一比较不支持 Fixed-K2 超越 Best-of-N。Property MAE 和选择共用 CHGNet 代理，E-hull/Stable 使用 MatterSim 代理；没有 DFT 证据，存在验证器偏差。单属性磁性密度任务上的结果不自动迁移到其他属性、材料域和 checkpoint。
