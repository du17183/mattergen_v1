# Pre-result design: budget-constrained trajectory search (2026-09-28)

This document defines the *new* experiments before observing their outcomes. Historical C1-128 and its frozen code/results stay immutable. The framework is a conceptual interface first, not a claim that Fixed-K2 has already beaten independent sampling.

## Interface and Fixed-K2 instance

**Search state** `s_t=(x_t,t,R_t,c,M)`: `x_t` is the complete batched diffusion state with `atomic_numbers`, fractional `pos`, `cell` and batch indices; `t` comprises discrete step and numerical timestep; `R_t` is Python/NumPy/CPU-CUDA RNG; `c` is the target condition (`dft_mag_density=0.1`); `M` identifies the frozen model/schedule. A portable new checkpoint should serialize or hash all components, including condition and schedule. The old C1 checkpoint has the batch and RNG and step index, but not a separately serialized condition or timestep tensor.

**Search action** is a predeclared suffix policy. The fixed bank is C0 continuation, GPulse, APulse, PPulse and CPulse. No learned allocator, new CFG tuning or post-result action change is permitted. **Transition** is the frozen MatterGen predictor–corrector sampler applied to a cloned state after restoring `R_t`. **Terminal verifier** is the frozen SAFE-A selector: CHGNet property MAE plus MatterSim E-hull/stability and evaluation validity. Novelty/uniqueness/NUS are aggregate quality outcomes, not selection inputs. If no safe improvement exists, return C0. **Budget** has separate ledgers for MatterGen score calls, CHGNet calls, MatterSim calls, elapsed wall/GPU time and peak allocated GPU memory. Record acquisition as well as per-method deployment cost.

Fixed-K2 is this interface with one checkpoint at step 400, width two (`GPulse+PPulse`), one common C0 continuation and terminal SAFE-A; generation cost `800 + 3×1200 = 4400` score calls (`2.2×` C0). It is closer to shared-prefix verifier-guided trajectory search/best-of-branches than CFG scheduling alone. It remains vulnerable to the interpretation “more candidates then choose”; the baseline below probes this rather than presuming the answer.

## Frozen new-study protocol

Two independent new cohorts of **128 primary seeds each**, neither overlapping historical registered C1/C2 or prior experiment seed files, will be registered and overlap-audited before generation. Within each cohort the **same primary seed is paired across methods**; this is required for paired bootstrap and W/T/L. “New seed for every K” means fresh versus historical/other cohorts, *not* disjoint between K arms, which would invalidate pairing. The independent sampler's second full seed is a separately registered deterministic child seed, never the primary seed. Cohort membership and child mapping are frozen by a manifest SHA-256 before generation. A new branch of code may be introduced only after this design and manifest are fixed; old C1 modules are not edited.

**Baseline cohort:** primary C0, Independent Best-of-2 (primary full C0 plus second independently seeded full C0), Fixed-K2 (the same primary C0/prefix plus GPulse+PPulse). Use identical frozen target, model, verifier, SAFE-A against primary C0, invalid-objective rule and paired evaluation. Independent candidate *is* a full second C0 draw; its terminal choice still falls back to primary C0. Independent Best-of-2 costs 4000 score calls (`2.0×`); Fixed-K2 costs 4400 (`2.2×`). Report the candidate-count and 10% generation-budget asymmetry conspicuously. Do **not** interpret a simple Fixed-K2 superiority as causal proof of branching. A positive paired gain with its 95% CI excluding zero and passing quality guardrails is evidence of an outcome difference at unequal compute, **not** proof of cost-efficiency or causal trajectory-search value; exact-budget controls remain necessary.

**Budget-scaling cohort:** nested C0-plus-K suffix search with frozen branch order `GPulse, PPulse, APulse, CPulse` for K=0,1,2,3,4. This preserves historical Fixed-K2 at K=2. All K arms use the same new primary seeds and identical C0 prefix; arms are recomputed from the same candidate pool, without outcome-based branch ordering. Generation costs are `2000,3200,4400,5600,6800` score calls (`1.0,1.6,2.2,2.8,3.4×`). Separate acquisition cost is reported; sharing cached candidate outputs for nested K does not change a method's deployment accounting. Each K has C0-reference gain, mean property MAE, 20,000-resample paired percentile 95% CI and W/T/L with `1e-12` tie tolerance. K2-vs-K1, K3-vs-K2 and K4-vs-K3 marginal gains are descriptive, with no post hoc selection of a new headline K.

Both studies report stable, E-hull, NUS, validity, novelty and unique rates, per-sample property error and compute. Primary endpoint is paired CHGNet absolute-error reduction, C0 minus method for within-cohort arms; the baseline study additionally reports Independent Best-of-2 minus Fixed-K2. Bootstrap uses a *predeclared* fixed PRNG seed and 20,000 independent resamples of paired seed rows. Guardrails versus C0: E-hull mean worsening <=0.01 eV/atom, stable/NUS/validity drops <=0.05 absolute; missing/nonfinite quality is failure, not silent exclusion. No DFT claim. No new method is declared successful solely by a favorable uncorrected multiple comparison.

**Execution discipline:** one sample per process/GPU worker, deterministic mode, no stochasticity-changing batch merge; only currently idle H20 GPUs. Log terminal outputs, process exit and timestamps in tmux-managed sessions. Freeze code/config/manifest hashes before first generation; stop on hash mismatch, seed overlap, failed exact C0 replay or missing per-seed output. Complete property, quality, selection, paired bootstrap, figure and report phases; partial outputs are labeled partial and never inserted into the final table as completed results. No adaptive-budget method is implemented in this stage.

**Decision language:** If Fixed-K2 does not beat Independent Best-of-2, the “beyond Best-of-N” claim is unsupported. If it does at the aforementioned asymmetric cost, say “a positive asymmetric-budget comparison, not proven trajectory-specific efficiency”. A fully defensible stronger paper claim would still need an exactly budget-matched/terminal-count matched control or independent verifier/DFT follow-up. Budget scaling can justify K=2 as a *trade-off* only if marginal gains flatten and quality stays acceptable; it cannot retroactively optimize the historical C1 method.
