# 章节写作计划

## 总体叙事

论文不是“两个互不相关模块”的拼接，而是围绕一个完整生成链条展开：

```text
采样阶段的条件控制（Adaptive CFG）
→ 生成后风险识别（Learned Gate）
→ 有界位置修正（E3-PCR）
→ 独立组合验证
→ 泄漏与失败路线审计
```

## 每章固定结构

每个方法/实验章节统一采用：

1. 研究问题与假设；
2. 方法定义与公式；
3. 实现边界和不改变的组件；
4. 实验协议、seed、n、基线和评价器；
5. 效应大小、95% CI、p 值和原始/配对图；
6. 结果解释；
7. 不能声称的内容；
8. 小结。

## 第3章写作要点

- 先解释固定 guidance 的局限，再给出三字段 residual 与 EMA，而不是从参数表开始。
- 明确 Predictor/Corrector 完整保留，排除与 Corrector Gating 混淆。
- 主结果写“正向趋势”，紧跟非显著性；摘要不可删掉这一限定。
- 参数放 Table 1，结果放 Figure 5/Table 2。

## 第4章写作要点

- 将“平均降力”与“有害修改率”拆为两个目标。
- E3-A 说明精修上限，E3-G 说明风险—收益折中。
- 先报告 C2 主效果，再报告 C3 Gate 机制；禁止倒置后暗示 E3-G 均值优于 E3-A。
- Win/Tie/Loss 在正式 256 使用原始连续差值口径；Gate-off 精确平局口径只在组合验证中单独说明。

## 第5章写作要点

- 两个 cohort 独立成节，最后并列讨论异质性。
- 不计算事后 pooled p-value，不包装成预注册 128。
- 第二 cohort 是更关键的复现证据，不能因效应较小而弱化。

## 第6章写作要点

- Leakage 诊断是可信研究的组成部分，不是主模型“第三创新”。
- 明确平均降力未明显被夸大，但安全率被显著高估。
- No-Go 路线用“假设—观察—停止证据—获得认识”结构，不写成流水账。
- 讨论 MatterSim 代理势、无 DFT、无真实目标属性验证和单数据域限制。

## 可执行写作里程碑

1. 冻结第3/4章公式与伪代码。
2. 将 Figure 1–12 与 Table 1–7 插入空白论文模板。
3. 先写每张图的“观察”和“限制”两句话。
4. 完成第3–6章初稿。
5. 回写绪论贡献点与摘要；不要先写摘要再逼迫结果符合摘要。
6. 最后做 Claim–Figure–Table 一致性检查。
