# 第3—5章数字格式规范

本规范只统一展示，不重算、不改写冻结结果。机器可读精确值以 `master_numbers.csv` 及其 `source_file` 为准；正文值按下表四舍五入。若正文与机器可读源发生实质差异，必须回到冻结源核验，不能用显示值反推。

| 数字类型 | 正文/表格格式 | 示例 |
|---|---|---|
| MAE、E-hull、MaxF、Mean Force、RMSD、绝对差值 | 小数点后6位 | 0.034796、0.158911 |
| 相对变化、比例、率 | 百分数，小数点后2位 | 29.81%、58.59% |
| 绝对量95% CI | 两端各6位 | [0.005817, 0.011391] |
| 相对量95% CI | 百分数，两端各2位 | [21.42%, 40.88%] |
| Spearman/Pearson相关系数 | 小数点后6位 | 0.925587 |
| \(p\) 值 | 3—4位有效数字的科学计数法 | \(3.422\times10^{-14}\) |
| W/T/L、样本数、调用次数、步数 | 整数；千位空格 | 254/0/2、20 000、4 400 |
| 计算倍率和时间比 | 倍率1位；时间比4位 | 2.2×、0.9980 |
| 冻结超参数 | 保留配置文件精度 | 0.0779514922、0.005 Å |

补充规则：

1. “改善”统一采用有利方向。对越低越好的量为基准减方法；对越高越好的量为方法减基准。
2. 区间必须注明是绝对差还是相对变化；两类区间不得直接比较大小。
3. 百分点变化使用“个百分点（pp）”，不得与相对百分比混用。
4. 负号统一使用数学负号或半角连字符中的一种，最终排版阶段统一；数值含义不得改变。
5. 冻结源中的更多小数位完整保存在 `master_numbers.csv`，章节正文不应混用7位、4位和6位显示。
