# 证据类型与结论强度规则

## 实验角色

| 类型 | 允许用途 | 不允许用途 |
|---|---|---|
| 探索实验 | 发现失败模式、提出后续假设 | 直接承担最终方法效果结论 |
| 机制实验/Oracle | 说明信息或可改善空间存在 | 当作可部署性能或总体效应 |
| 消融实验 | 排除替代解释、定位组件作用 | 自动证明组件必要或全局最优 |
| 先导实验 P0 | 按冻结门槛决定是否继续 | 替代 Formal256 的最终证据 |
| 模型选择/验证 | 冻结候选、参数或停止路线 | 在同一数据上报告无偏确认效果 |
| 留出测试 | 检查选型后的方向与泛化 | 小样本区间跨零时宣称优势 |
| 正式确认 | 在冻结方法、指标和新种子上承担主结论 | 超出任务、checkpoint和代理协议外推 |
| 独立代理评估 | 检查效应是否跨未参与引导的代理模型保持 | 称为 DFT、实验或完全独立物理验证 |

## 状态解释

| 状态 | 统一解释 |
|---|---|
| `SUPPORTED` | 冻结 cohort、指标及代理协议支持该窄主张 |
| `SUPPORTED_MECHANISM` | 支持机制或上界，不支持部署效果 |
| `SUPPORTED_GUARDRAIL` | 已注册护栏未被破坏；不表示所有质量指标改善 |
| `SUPPORTED_INDEPENDENT_SURROGATE` | 未参与在线引导的代理模型给出方向支持；仍非 DFT |
| `DIRECTIONAL_ONLY` | 点估计有利但确认强度不足或区间跨零 |
| `MIXED` | 指标、cohort或尾部方向不一致 |
| `NOT_SUPPORTED` | 当前预注册证据不足以支持目标命题；不是证明命题永远错误 |
| `FAIL` | 未通过该实验预先冻结的继续/兼容门槛 |
| `FALSE` | 证据包明确不存在该验证，如 `DFT_VERIFIED=false` |

全文主张规则：先写实验角色，再写效应与不确定性，最后写边界。不得用探索性 Oracle、P0 或描述性均值覆盖正式负结论；不得把未违反护栏写成全面改善；不得把跨代理方向保持写成真实物理验证。

## 论文主张强度五级映射

为便于第1章、第6章和摘要复用，论文层级统一为：`SUPPORTED`（确认支持）、`DIRECTIONAL`（仅方向性，对应源状态 `DIRECTIONAL_ONLY`）、`MIXED`（证据混合）、`NOT_SUPPORTED`（未获支持）和 `NOT_VERIFIED`（未执行所需验证）。冻结源中的更细状态保留不改；例如 `SUPPORTED_INDEPENDENT_SURROGATE` 映射为带代理限定的 `SUPPORTED`，`DFT_VERIFIED=false` 映射为 `NOT_VERIFIED`，而不是把源状态改写成正结论。
