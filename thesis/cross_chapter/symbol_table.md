# 第3—5章统一符号表

| 符号 | 含义 | 作用域/备注 |
|---|---|---|
| \(x_t\) | 时间 \(t\) 的含噪扩散状态 | 通用概念符号 |
| \(x_0\) | 扩散终态/干净结构 | 与预测量 \(\hat{x}_0\) 区分 |
| \(\hat{x}_0(x_t,t)\) | 由 \(x_t\) 恢复的预测干净结构 | RC-NFGD；三个字段按实际 SDE 分别解析，不可强行用单一公式替代 |
| \(z_t\) | MatterGen 完整采样器状态 | 创新点1算法，包括原子、位置、晶胞等内部状态 |
| \(a_t,p_t,H_t\) | 原子类型、分数坐标、晶胞矩阵字段 | 晶胞统一用 \(H\)，不再用 \(L\) |
| \(s_{\mathrm{cond}},s_{\mathrm{uncond}}\) | 条件/无条件得分 | 避免与策略下标混淆 |
| \(g\) | CFG 强度 | 标准公式中的统一记号；不用 \(w\) 表示同一量 |
| \(g_a,g_p,g_H\) | 原子、位置、晶胞字段的 CFG 强度 | C0 时三者均为2.0 |
| \(\Delta_a,\Delta_p,\Delta_H\) | 三字段条件—无条件得分残差 | 创新点1在线探索；大写 \(\Delta\) |
| \(T\) | 总采样步数 | 本研究 \(T=1000\) |
| \(t_b\) | 创新点1分支步 | \(t_b=400\) |
| \(K\) | 候选分支预算 | Fixed-K2 中 \(K=2\) |
| \(P_k\) | 第 \(k\) 个候选后缀策略 | \(P_0\) 为 C0 后缀 |
| \(\xi_{t_b}\) | 分支点随机数生成器状态 | 与 \(z_{t_b}\) 一起保存和恢复 |
| \(y_k\) | 第 \(k\) 条后缀的终点结构 | \(y_0\) 为精确 C0 |
| \(e(y),v(y),s(y),h(y)\) | 属性误差、有效性、稳定性、E-hull | 创新点1终点接受约束 |
| \(\mathcal A\) | 通过属性与质量约束的候选集合 | 空集时安全回退至 \(y_0\) |
| \(F_i\) | 第 \(i\) 个原子的笛卡尔力向量 | RC-NFGD，单位 eV/Å |
| \(r_i\) | 第 \(i\) 个原子的笛卡尔坐标 | \(r_i=f_iH\)，单位 Å |
| \(\bar F\), \(\widetilde F_i\) | 平均平移分量、去中心化力 | \(\widetilde F_i=F_i-\bar F\) |
| \(f_t\) | 当前分数坐标 | 不与力 \(F_i\) 混用 |
| \(H_t\) | 当前晶胞矩阵 | 笛卡尔/分数坐标映射 |
| \(\delta f_i\) | 第 \(i\) 个原子的分数坐标修正 | 小写 \(\delta\)，与字段残差 \(\Delta_f\) 区分 |
| \(\Delta_f\) | 文献或统一讨论中的字段残差占位符 | 若指位置字段应写 \(\Delta_p\)；不得误作分数坐标位移 |
| \(F_{\mathrm{ref}}\) | 力归一化参考尺度 | 冻结值0.0779514922 eV/Å |
| \(\eta\) | 名义笛卡尔位移尺度 | 冻结值0.005 Å |
| \(\delta_{\max}\) | 单事件硬位移上限 | 冻结值0.01 Å |
| \(c_t^f\) | 注入 position predictor 的得分修正 | 只改位置 predictor |
| \(R_m\) | 指标 \(m\) 的有利相对变化 | 越低越好时为 \((C0-method)/C0\) |

已解决的符号冲突：条件/无条件得分由简写 \(s_c,s_u\) 统一为 \(s_{\mathrm{cond}},s_{\mathrm{uncond}}\)；晶胞字段由 \(L\) 统一为 \(H\)。未解决符号冲突为0。
